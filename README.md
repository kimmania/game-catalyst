# Catalyst

An alchemy-lab color-compounding puzzle for iPad and mobile browsers. Install it as a PWA and play offline.

**Live:** https://kimmania.github.io/game-catalyst/

## Gameplay

You are an apprentice in the Alchemy Guild. Your masters demand pure elemental reagents, but the vials always get mixed up on the bench.

- **Tap a source beaker, then a destination** to pour reagents.
- **Reactions:** Pouring one primary reagent onto another triggers a color reaction from the Reaction Table. The Guild has documented **15 unique cross-color reactions** — from classics like Crimson + Amber → Orange to rare fusions like Cobalt + Violet → Turquoise.
- **Solidification:** Pouring a primary onto the same color creates a permanent crystal, permanently reducing that beaker’s capacity. This happens automatically as part of normal sorting and no longer penalizes your star rating.
- **Catalyst:** Splits an intermediate color back into its parents. Charges are limited per level.
- **Goal:** Each beaker must contain only one color (layers + crystals combined).
- **Target moves:** Shown next to the move counter; beat it for a higher star rating.
- **The Grimoire:** Every new reaction you create in the crucible is recorded in your persistent Grimoire, accessible from the map.

### Controls

- **Mouse / touch:** Tap a source beaker, then a destination.
- **Keyboard:** Arrow keys move selection; Enter/Space selects or pours; **C** uses Catalyst; **U** or **Ctrl+Z** undoes; **?** opens help.

### Star Rating

| Stars | Condition |
|-------|-----------|
| ⭐ | Complete the level |
| ⭐⭐ | Complete within 1.5× target moves |
| ⭐⭐⭐ | Complete within target moves |

The target move counts are generated estimates rather than solver-proven optima, so earning 3 stars is intentionally attainable.

## Tech Stack

- Vite + TypeScript (ES modules)
- `vite-plugin-pwa` for service worker and manifest
- Vanilla DOM rendering — no framework
- Mobile-first CSS with safe-area insets
- `prefers-reduced-motion` / `.reduced-motion` respected for animations
- ARIA live region announces reactions, invalid moves, and star ratings
- 15-color Reaction Table with persistent Grimoire discovery tracking
- Puzzle banks generated by a Python random-distribution script; difficulty-scaled target moves are estimates, not solver-proven optima
- Generator rejects/repairs levels that would start with solid-color beakers

## Development

```bash
npm install
npm run generate-puzzles   # regenerate puzzle JSONs when you want to refresh the static bank
npm run dev                # local dev server
npm run build              # production build in dist/
```

The JSON files in `public/puzzles/` are committed static assets. Run `npm run generate-puzzles` manually whenever you want to overwrite them.

## Deployment

GitHub Actions builds and deploys `dist/` to GitHub Pages on every push to `main`. See `.github/workflows/deploy.yml`.

The `base` path in `vite.config.ts` is set to `/game-catalyst/` for subdirectory hosting.
